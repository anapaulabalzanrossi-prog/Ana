# Minha Agenda

Agenda pessoal e de trabalho em formato de web app instalável (PWA), pensada para iPad, iPhone e Mac.

- **Hoje:** painel com tarefas do dia, atrasadas, prazos fatais com contagem regressiva, trabalho por status e prioridades da semana.
- **Tarefas:** captura rápida, separação trabalho/pessoal, status (Falta documento, Falta ler, Fazer petição, Protocolar…), cliente, nº do processo, prazo fatal, etapas e lembretes. Visão em lista ou em quadro por status.
- **Agenda:** visões de dia, semana (estilo planner, com prioridades e notas da semana) e mês, integradas à Google Agenda.
- **Ideias:** notas soltas com #etiquetas, cores e escrita à mão com Apple Pencil.
- **Wishlist:** desejos com foto, preço, link e categoria.

Configuração: veja o [GUIA.md](GUIA.md).

Tecnologia: HTML, CSS e JavaScript puros (sem etapa de build), Firebase (Auth + Firestore) para sincronização e Google Calendar API para compromissos e notificações.
